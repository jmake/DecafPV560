
## SpicyViewer 

A powerful medical image viewer has been developed with a robust C++ wrapper designed to seamlessly handle and visualize multiple imaging formats, including DICOM and NIfTI. 

This high-performance solution ensures fast and reliable image loading, making it ideal for clinical and research environments that demand precision and interoperability. 

Its modular architecture allows for easy integration into existing systems, offering a professional-grade tool for advanced medical imaging workflows.
